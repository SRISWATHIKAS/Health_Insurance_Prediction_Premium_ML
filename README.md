# Health Insurance Premium Prediction
# 📌Overview

Health insurance premiums vary depending on several factors such as age, BMI, smoking habits, gender, region, and number of children. This project focuses on building a Machine Learning model to predict health insurance premiums based on customer information.

The project uses Linear Regression techniques to understand how different customer characteristics influence insurance charges and to predict premiums for new customers.

## 🎯 Objective

The main objectives of this project are:

- Predict health insurance premiums based on customer details.
- Understand the factors that influence insurance charges.
- Compare different Linear Regression models.
- Evaluate model performance using appropriate regression metrics.
- Predict insurance charges for unseen customer data.
